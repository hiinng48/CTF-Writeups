## Basic Data Types and Sizes

When source code compiles to machine instructions, high-level abstractions (variable names, types, structs, signedness) are stripped away. The CPU and memory operate strictly on raw bytes and register widths.

### Quick Reference Cheat Sheet

| Name | Size | C Equivalent | x86_64 Registers | Common Usage / Value Range |
| :--- | :--- | :--- | :--- | :--- |
| **Byte** | 1 byte (8 bits) | `char`, `uint8_t`, `int8_t` | `al`, `bl`, `cl`, `dl`, `r8b` | ASCII characters, boolean flags (`0` to `255` / `-128` to `127`) |
| **Word** | 2 bytes (16 bits) | `short`, `uint16_t`, `int16_t` | `ax`, `bx`, `cx`, `dx`, `r8w` | Short integers, UTF-16 characters |
| **Dword** (Double Word) | 4 bytes (32 bits) | `int`, `uint32_t`, `long` (Win32) | `eax`, `ebx`, `ecx`, `edx`, `r8d` | Standard integers, loop counters, 32-bit pointers |
| **Qword** (Quad Word) | 8 bytes (64 bits) | `long long`, `uint64_t`, pointers | `rax`, `rbx`, `rcx`, `rdx`, `r8` | 64-bit pointers (memory addresses), 64-bit integers |

### Ghidra `undefined` Types

When Ghidra detects data or a variable but cannot yet infer whether it is a signed/unsigned int, float, pointer, or struct, it assigns a placeholder type:

* **Format:** `undefinedN` where `N` = byte size.
    * `undefined1` $\rightarrow$ 1 byte (Byte)
    * `undefined2` $\rightarrow$ 2 bytes (Word)
    * `undefined4` $\rightarrow$ 4 bytes (Dword)
    * `undefined8` $\rightarrow$ 8 bytes (Qword)
* **Ghidra Tip:** Highlight the variable and press `Ctrl+L` (or right-click $\rightarrow$ *Retype Variable*) to assign the real type (e.g. `int`, `char*`) once you figure out how it is used.

## How srand(), rand(), and time() work

Computers are deterministic machines and cannot generate true random numbers on their own. Instead, standard C libraries use a **Pseudo-Random Number Generator (PRNG)** algorithm.

### Mental Model: The Pre-Printed Book
* **The PRNG**: Imagine a giant book filled with billions of pre-determined numbers in a fixed order.
* **`rand()`**: Reads the next number in the book and advances to the next position.
* **`srand(seed)`**: **Selects which page to open.** Given the exact same seed, the program opens to the exact same page every single run.
* **`time(NULL)`**: Returns the current UNIX epoch time (seconds since January 1, 1970). Because this number increments once every second, it is frequently used as a dynamic seed.

### Typical Pattern in C

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
    // Seed the PRNG with the current timestamp in seconds
    srand((unsigned int)time(NULL));

    // Generates numbers according to the chosen seed
    printf("%d\n", rand());
    printf("%d\n", rand());
    return 0;
}
```

## 3. Endianness (Byte Ordering)

x86 and x86_64 architectures use **Little Endian** representation: the least significant byte is stored at the lowest memory address.

* **Little Endian** (x86 / ARM default):
    * Value: `0x12345678`
    * Stored in memory as: `\x78 \x56 \x34 \x12`
* **Big Endian** (Network Byte Order):
    * Value: `0x12345678`
    * Stored in memory as: `\x12 \x34 \x56 \x78`
* **RE Note:** When inspecting raw hex in Ghidra or Hex Editors, multi-byte constants appear reversed compared to their numeric representation.
