## How srand(), rand(), and time() work?

- Computers are deterministic machines—they cannot produce truly random numbers on their own. Instead, they use an algorithm called a Pseudo-Random Number Generator (PRNG).

- Think of the PRNG as a giant book filled with billions of pre-calculated, scrambled numbers:

    - rand(): Reads the next number in the book. Every time you call rand(), it moves to the next line and gives you a number.

    - srand(seed) (Seed Random): Tells the computer which page of the book to open to.

    - time(): Returns the current time in seconds since January 1, 1970 (the epoch). This value changes every second, so it can be used as a seed for srand() to get different random numbers each time you run the program.

-> Use time() to get a seed value that changes every second, so you get different random numbers (different pages) each time you run the program.

E.g: 
    srand(time(NULL));
    printf("%d\n", rand()); 
    printf("%d\n", rand());

will give you different numbers each time you run the program because the seed (time) changes every second.
